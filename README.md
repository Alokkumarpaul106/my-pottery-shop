# Pottery Shop
This is a Pottery Shop project that i am developed using Tailwind css, react, Python ,Django Rest Framework. I created this project to practice frontend and backend development skills and build in a real world ecommerce system.

##  Features

* Browse handmade pottery and home decor products
* Product search and filtering
* Add products to cart
* Order and delivery management
* Payment-related functionality
* Customer management
* Fully responsive design
*  Admin panel for product and order management
* Clean and modern user interface

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Django
* **Database:** MySQL
* **Tools:** VS Code, Git & GitHub

## Project Goal

The main goal of this project is to create a professional online platform where customers can easily discover and purchase handmade pottery and traditional products.

It also aims to support local craftsmanship by bringing handmade products to a wider audience through e-commerce.
